# Skill: memory-bank-sync

## Propósito
Guiar al agente para mantener sincronizado el banco de memoria con el estado real del repositorio.

## Cuando usar
- Al terminar cambios funcionales o estructurales.
- Cuando cambie el estado del roadmap, riesgos o próximos pasos.

## Entradas esperadas
- Lista de archivos modificados.
- Resumen de cambios implementados.

## Salida esperada
- Actualización de memory-bank/activeContext.md y/o memory-bank/progress.md cuando aplique.
- Nota explícita si no fue necesaria actualización de memoria.

## Criterio de calidad
No debe haber contradicciones entre documentación de memory-bank y código fuente.
