# backoffice

Internal dashboard UI for HealthCore built with Next.js + TypeScript.

## Purpose

This app provides a private operational view and renders business logic results from milestone 2 by importing shared logic directly from the monorepo `src/` folder.

## Run locally

```bash
cd uis/backoffice
npm install
npm run dev
```

Open http://localhost:3000/

## Validation

```bash
npm run typecheck
npm run lint
```
